1. Bug Inventory Matrix

ID Category Severity Symptom Root Cause Fix Strategy
BUG-01 Logical Critical Attack prompts using uppercase (e.g., "IGNORE PREVIOUS INSTRUCTIONS") completely bypass detection. RegExp literal lacks the "i" flag, enforcing strict lowercase ASCII matching only. Fixed Append the "i" modifier and precompile to an immutable static pattern.
BUG-02 Boundary / Null High Substrings spanning window boundaries (e.g., 3-word trigger phrases) miss the 3rd word and are ignored. Array.prototype.slice end argument is non-inclusive; subtracting 1 causes only 2 tokens to be taken instead of 3. Fixed Pass (i, i + windowSize) so that exactly 3 tokens are extracted in each sliding step.
BUG-03 Type Coercion High Risk score becomes string concatenation ("040"), distorting arithmetic comparisons and evaluation thresholds. Weakly typed dynamic addition where numeric 0 concatenated with string "40" yields "040" rather than 40. Fixed Enforce strict TypeScript numeric types (number) and explicit integer addition.
BUG-04 Boundary / Null Critical Calling sanitizePrompt without context or with context: {} throws uncaught TypeError: Cannot read properties of undefined. Direct deep property access on optional parameter without optional chaining or defensive falsy check. Fixed Use optional chaining context?.metadata?.environment with nullish coalescing default value fallback.
BUG-05 Security / ReDoS Critical Processing a 30-character repetitive malicious string hangs Node.js/Vite thread with 100% CPU usage. Nested unbounded quantifiers (a+)* trigger exponential backtracking O(2^N) permutations on non-matching suffix. Fixed Flatten regular expression into deterministic linear pattern and add max input length boundary guard.
BUG-06 Logical Critical Admin users with safe score (e.g. 0) are incorrectly rejected (isSafe = false), while malicious admins pass! Ternary condition has inverted branch logic (riskScore > 50 evaluated as safe for admins). Fixed Correct the comparison operators: admins are permitted elevated threshold (score < 80) vs standard users (score < 50).
BUG-07 Logical High Consecutive identical calls with valid API keys alternate between true and false! RegExp with global (/g) flag retains stateful lastIndex pointer across subsequent .test() executions. Fixed Remove the global flag for boolean tests or reset lastIndex = 0 before execution.
BUG-08 Logical Medium Prompts containing multiple credit card numbers only redact the first card, leaking the rest! String.prototype.replace with non-global regex only replaces the first occurrence. Fixed Use global flag /g with word boundaries \b to mask all instances in the payload.

3. Lessons Learned
